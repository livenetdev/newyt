# YouTube Redesign

YouTube UI that doesn't make you sick. Common-sense features and customizability.

**[Download the extension](https://github.com/livenetdev/newyt/releases/latest/download/youtube-redesign.zip)**
· Chrome 111 or later, and other Chromium browsers · free, from Livenet

## Install

1. Download the zip and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.

## Updating

Download again from the link above, unzip it over the old folder, and click the reload button on the extension's card.
Only the newest version is kept here.
